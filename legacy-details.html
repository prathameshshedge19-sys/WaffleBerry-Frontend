    What these terms mean

    Story Sessions
    The number of guided Story conversations started for this Legacy.
    Distinct Chapters
    The number of different life-story chapters with at least one Story Session.
    Story Contributions
    The number of user-authored Story messages saved.
    Total Memories
    All extracted memories, including those awaiting review or already reviewed.
    Approved Memories
    Memories explicitly approved for use by the Legacy Persona.
    Linked Conversations
    Companion conversations connected to this Legacy.
    Story Session Progress
    Completion status only for Story Sessions that have already been started. It does not measure all possible future stories.

    The process that converts Story contributions into reviewable memory candidates.
